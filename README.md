# PulseView

PulseView is a lightweight media-intelligence dashboard for monitoring YouTube content, audience signals, and live engagement. It ships as a static, installable PWA and deploys directly through GitHub Pages.

## Run locally

```bash
python3 -m http.server 4173
```

Open <http://localhost:4173>.

## Test

```bash
node --test tests/*.test.mjs
```

## Deployment

GitHub Pages serves the root of the `main` branch at <https://kishore583583.github.io>.
